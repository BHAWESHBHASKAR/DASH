# P0 status register (v0.3.0)

Date: 2026-10-09
Status: **Code merged in this tree; release not tagged.** This register follows the rule in [master plan section 9](./2026-10-09-production-readiness-master-plan.md): a status line links evidence (a test, a CI job, or a file) or it does not count. It reports what the tree contains, not what CI last printed; "test exists" means the function is present and was listed by `cargo test --workspace -- --list`. Pass or fail is the CI result.

Scope: the P0 work packages P0.1 to P0.10 of the master plan, with the issue IDs they cite in the [issue register](./2026-10-09-issue-register.md). Test paths are `path::name`.

Legend: **Landed** (code merged and a test or CI check named below covers it), **Landed, gap** (merged; the gap column says what is not covered or not done), **Open** (not done).
