## Method and limits

- An issue is **CLOSED** only when the fix is present in the code on this commit and at least one named test exercises the fixed behavior and passed in the single `cargo test --workspace` run recorded above (the per-test result was read from that run's log; Java, Go, TypeScript and Python results are from separate runs, listed below). **PARTIAL** means the fix exists but a test is missing, cannot fail on the old behavior, or part of the fix is missing. **OPEN** means no fix. **N/A-SUPERSEDED** was not needed.
- Whether a test would fail on the old code was judged by reading the test and the fix; the old code was not rebuilt and re-run for each issue.
- Deploy and documentation items are verified by reading the files and by the validators that could run here; for those, the Notes column says what was and was not run. Their closed status rests on that reading, not on a failing-then-passing test.
- Issues whose Phase column has no `P0` are listed as `open (phase X)`. Where the commit history shows early work on them, the Notes column mentions it; those rows were not audited for closure.
- Scope note: where the Phase column is split (for example `P0 / P2`), the status refers to the P0 part; the later part is named in Notes.

## Behavior changes operators must know

Each item is taken from the code or its tests on this commit; the source is given in parentheses.

- **Authentication is deny-by-default.** A service with no API key, scoped key, JWT secret or OIDC config rejects every non-probe request and refuses to start. `DASH_INSECURE_DEV_MODE=1` re-opens it and forces a loopback bind unless `DASH_INSECURE_DEV_MODE_ALLOW_NON_LOOPBACK` is set (services/common/src/policy.rs:12, services/common/src/lib.rs:184,247).
- **Strict secrets are on by default.** `DASH_STRICT_SECRETS` defaults on (off only with dev mode). API keys and replication tokens need at least 16 characters, HS256 JWT secrets at least 32. Placeholder values (`change-me`, `replace-me`, `example`, `<...>`, values starting `secret`/`password`) are rejected, and the error text does not echo the value (services/common/src/lib.rs:86-135,189).
- **Environment variable names.** Ingestion reads `DASH_INGEST_*` (not `DASH_INGESTION_*`). Ollama is configured with `DASH_OLLAMA_ENDPOINT`; `DASH_OLLAMA_BASE_URL` is a deprecated alias and a base URL without a path is expanded to `/api/embed` (pkg/embeddings/src/lib.rs:251-270). `DASH_LOG_LEVEL`, `DASH_*_TRANSPORT_RUNTIME` and `DASH_*_JWT_PUBLIC_KEY` are not read (docs-site/docs/reference/configuration.md:230-234).
- **New required secrets.** Compose requires seven values and refuses to start without them: ingestion API key and HS256 secret, retrieval API key and HS256 secret, both replication tokens, and the control-plane token (deploy/container/docker-compose.yml:69-149). Generate them with `scripts/generate-secrets.sh` (mode 0600). The control plane needs `DASH_CONTROL_PLANE_TOKEN` and refuses to start without it outside dev mode; the metadata-router client sends `DASH_ROUTER_CONTROL_PLANE_TOKEN`.
- **Replication endpoints are closed by default.** `/internal/replication/*` on ingestion answers only when `DASH_INGEST_REPLICATION_TOKEN` is set and sent as `x-replication-token` (constant-time compare); with no token they stay closed unless dev mode is on (services/ingestion/src/transport/replication.rs:478-490). Replication still uses plain `http://` only (services/retrieval/src/replication.rs:1066).
- **Rate limiting is now enforced.** A per-tenant token bucket applies to API-key, JWT and OIDC requests and returns 429 with `Retry-After`. Defaults: retrieval 500 rps burst 1000; ingestion 100 rps burst 200 (`DASH_*_RATE_LIMIT_PER_TENANT_RPS`, `DASH_*_RATE_LIMIT_BURST`; services/*/src/transport/authz.rs:17-18).
- **Roles, tokens and OIDC.** A JWT without a role claim gets no roles unless `DASH_*_JWT_DEFAULT_ROLES` is set; unscoped legacy API keys get `DASH_*_API_KEY_DEFAULT_ROLES` (default: the service's primary role). `exp` is required, lifetime is capped (default 86400 s, `DASH_*_JWT_MAX_LIFETIME_SECS`), leeway is capped at 60 s, a `*` tenant claim is ignored unless `DASH_*_JWT_ALLOW_WILDCARD_TENANT` is set, and OIDC needs `aud`, `iss` and an https JWKS URL (loopback or `DASH_OIDC_ALLOW_INSECURE_JWKS=1` excepted). Revoked `jti` values are denied (`DASH_*_JWT_REVOKED_JTIS[_PATH]`). The policy is built once at start and reloaded on SIGHUP (pkg/auth/src/lib.rs, services/common/src/policy.rs:1127-1230).
- **Previously open routes need credentials.** `/v1/embeddings`, `/metrics` and `/debug/*` require authentication; `/metrics` can be made public only with `DASH_METRICS_PUBLIC=1`. Health, live and ready probes stay open. Authorization now happens before any embedding-provider call (services/retrieval/src/transport.rs:1403-1427; services/ingestion/src/transport/read_routes.rs:76).
- **HTTP limits.** Header line over 8 KiB, header block over 32 KiB, or more than 100 headers returns 431; `Transfer-Encoding: chunked` returns 501; conflicting duplicate `Content-Length` returns 400; body over 16 MiB returns 413; JSON nesting beyond 64 returns 400; the whole request must arrive within `DASH_HTTP_REQUEST_TIMEOUT_MS` (default 10000) or the connection is dropped with 408 (services/retrieval/src/transport/http.rs:11-47, payload.rs:395; services/ingestion/src/transport/request.rs:11-47). Accept errors no longer stop the server.
- **Evidence and edges are upserts.** Evidence is keyed by `evidence_id` and edges by (from, to, relation); re-ingesting replaces rather than appends, so citation counts that were inflated by earlier restarts will drop after a rebuild from the WAL (pkg/store/src/lib.rs:2778-2796).
- **Batch ids and idempotency.** A known `commit_id` with unchanged content is an idempotent replay; the same `commit_id` with changed content is now an update, reported with `updated: true`, instead of being dropped. Document and claim ids are derived without tenant/document collisions, so ids generated for the same input differ from those of older versions (services/ingestion/src/transport.rs:490-545; services/ingestion/src/extraction.rs:823).
- **Identifier validation.** Control characters (tab, newline, etc.) in tenant, claim, entity, embedding and evidence/edge identifiers are rejected at validation (pkg/schema/src/lib.rs:188).
- **WAL format and recovery.** New WAL records are versioned and checksummed; a torn final record is truncated at open; a bad checksum in the middle is an error naming the line. Pre-checksum records are still read. By default unreadable legacy records are quarantined to a side file and replay continues; set `DASH_WAL_REPLAY_STRICT=1` to fail instead (pkg/store/src/wal.rs:91-118). A `<wal>.generation` file identifies the WAL lineage and changes at every checkpoint/compaction. Use `tools/wal-inspect` (`inspect`, `verify`, `repair`) before manual surgery. Older binaries predate the versioned record format and are not expected to read WALs written by this version.
- **Replication protocol.** Frames carry the WAL generation. Followers persist (generation, offset) and resync from a snapshot after leader compaction or an unknown generation, replacing their state instead of merging; delta frames never split a commit group; retrieval readiness reports follower lag and a dead leader (`DASH_*_REPLICATION_MAX_STALENESS_MS`). An old offset-only state file is accepted (services/retrieval/src/replication.rs, pkg/store/src/wal.rs:386-433).
- **Atomic ingest.** A single ingest is written as one WAL commit group; an incomplete group is discarded on replay. If the checkpoint after a committed write fails, the response reports the checkpoint as deferred rather than returning an error (pkg/store/src/wal.rs:181-260; services/ingestion/src/transport/tests/write_path.rs).
- **Ranking.** Support and contradiction edges now count toward the target claim, not the author; dangling and cross-tenant edges are ignored; the support bonus and contradiction penalty saturate; repeated evidence from one source counts once. Result scores and order change relative to earlier versions (pkg/store/src/lib.rs:2071-2145, pkg/ranking/src/lib.rs:82-107).
- **Cross-tenant errors.** A claim-id conflict with another tenant returns a conflict that does not name the other tenant. Vector and lexical fallbacks no longer search other tenants (pkg/store/tests/semantics_query.rs).
- **Segment directories moved.** Per-tenant segment directories use an injective name; a legacy directory is migrated once on first use. Segment files are never overwritten in place, and unreferenced files are pruned only after a grace period (services/indexer/src/lib.rs:138-192,410-523).
- **Embedding providers.** Provider calls use a TLS-capable client with bounded bodies, retries and a single-probe circuit breaker. Credentials over plain `http://` are refused for non-loopback hosts unless `DASH_EMBEDDING_ALLOW_INSECURE_HTTP` is set. Token-array input to `/v1/embeddings` is rejected unless enabled, and provider failures return short error codes without internal detail (pkg/embeddings/src/http.rs:73-117; services/retrieval/src/openai_embeddings.rs).
- **Placement and control plane.** Ingestion stops accepting writes once the placement source has been failing longer than `DASH_INGEST_PLACEMENT_STALE_GRACE_MS` (default 30000), and epoch regressions are rejected. The metadata-router client no longer falls back to a stale placement file unless `DASH_ROUTER_ALLOW_STALE_PLACEMENT` is set. Control-plane promotion refuses an unknown or lagging replica unless forced. The lease is durable and carries a fencing token (services/ingestion/src/transport/placement_routing.rs:18; services/metadata-router/src/lib.rs; services/control-plane/src/leader.rs).
- **Audit log.** Ingestion and retrieval write one canonical record format that the shared verifier (`tools/audit-verify`, `scripts/verify_audit_chain.sh`) accepts; legacy lines still verify; a torn tail is truncated and writes are file-locked. Audit remains off unless `DASH_INGEST_AUDIT_LOG_PATH` / `DASH_RETRIEVAL_AUDIT_LOG_PATH` is set; compose and k8s config now set them (services/common/src/audit.rs).
- **Deployment artifacts.** Compose ports bind 127.0.0.1, containers run read-only with all capabilities dropped, and binaries are root-owned. Kubernetes/Helm no longer mount an `emptyDir` over `/opt/dash`, wire retrieval to ingestion for replication, route `/v1/ingest*` to ingestion, probe `/v1/ready`, and no longer ship HPAs or default secrets (Helm refuses to render without secrets, or with placeholders). Images are named `ghcr.io/<owner>/dash-<service>`. systemd units use per-service state directories.
- **SDKs.** Java, Kotlin and C# no longer expose `delete`; ingest is marked experimental, goes to a separate ingestion URL, and is not retried unless an idempotency key is set; the retrieve default omits `top_k` so the server default (5) applies; the C# retrieve model reads `results` with a numeric score. SDK version is 0.2.0 across languages.
